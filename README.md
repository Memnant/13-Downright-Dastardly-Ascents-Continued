# 13 Downright Dastardly Ascents Continued

**13DDA 天阶延续版**：在 PEAK 新版中延续 pooblives 的高难度天阶设计，并补充雾沼、城塞等区域的规则。

本项目基于 [pooblives 的 13 Downright Dastardly Ascents](https://thunderstore.io/c/peak/p/pooblives/13_Downright_Dastardly_Ascents/)，属于独立维护的社区续作，不代表原作者或 PEAK 官方。续作维护：**Memnant**。

## 和原模组的关系

对比基准是原作者 **Thunderstore 1.4.4 发布包**。其 DLL 与本项目恢复源码时使用的样本逐字节一致；该 DLL 内部仍标为 `1.3.1`，所以不能仅凭插件显示版本区分原作者的发布包。龙卷风落地操作另参考 **1.4.2**。版本和哈希依据见 [来源说明](docs/UPSTREAM.md)。

续作保留 9–20 的编号、主要难度主题和逐阶叠加方式。选择 N 阶时，游戏的基础等级使用官方天阶 8，模组另行记录 9 到 N 的追加规则。例如，选择 20 会叠加 9–19，再应用本页列明的 20 阶地区例外。

原作者旧天阶 8 的强化追赶雾已经移到续作 **18 阶**。官方 7 的复活诅咒与官方 8 的通关流程继续运行；续作挑战不自动修改官方解锁进度。原模组的旧版复活限制、自动解锁和超出旧天阶范围后强制回机场的逻辑不再沿用。

以下“相同”指保留设计与已核对的主要参数，不表示补丁实现逐行相同，也不表示已经完成全部实机、联机验证。

### 雾沼睡眠的叠加关系

下面按正常逐阶累加、环境雾与追赶雾都在作用时计算。基础环境雾提交 `0.009/秒`；被追上另提交 `0.018/秒`。

| 条件 | 环境雾 + 追赶雾提交总量 | 白天自然恢复参数 | 夜间自然恢复 |
|---|---|---|---|
| 18、19 阶雾沼 | `(0.009 + 0.018) ×1.3 = 0.0351/秒`，约 **3.51 点/秒** | 约 **0.33 点/秒**，为 16 阶日间基准的 1/6 | 0 |
| 20 阶雾沼 | `0.009 + 0.018 = 0.027/秒`，约 **2.7 点/秒**；取消 17 阶困倦加成 | 约 **0.67 点/秒**，为 16 阶日间基准的 1/3 | 0 |
| 18–20 阶城塞 | 不增加雾沼追赶雾；环境倦霾继续受 17 阶困倦倍率影响 | 约 **0.33 点/秒** | 0 |

增长与恢复不是无条件直接相减：原版环境延迟、恢复冷却、安全区、蜡烛和状态上限仍生效。曼德拉草、食物和跌落不会被当作环境雾额外追加两倍。火山/雾沼的 150 米只改变显示距离，不提前触发状态伤害。

### 天阶 20 的缓冲和保护

- **天气缓冲 30 秒**：新开局等房主载入且人物苏醒后计时；原生营火续玩等恢复完成后计时。期间暂停雪暴、风暴、暴雨的推力和状态效果，龙卷风不参加该缓冲。
- **新局保护 30 秒**：选择续作 20 新开局时，全队共享原版无敌窗口；原版对诅咒、石化等的例外保留。营火续玩不会重新发放无敌，单独强制 20 的官方局也没有此保护。
- 晚加入或重连继承房主窗口的剩余时间，正常换区域不重新发放。这些联机路径已做代码/模拟检查，真实双客户端行为仍需验证。

## 房主选项：免宝石通关

在机场面板切换 **“免宝石通关”**，默认关闭，适用于续作 **9–20**。

开启后，顶峰雕像直接提供原版“童军的荣耀”，省去收集四颗宝石和献祭步骤，之后的原版通关流程仍须完成。选项在开局时固定，并随营火存档记录；机场修改只影响新局。官方模式不受此选项影响。这是续作新增功能。

## 安装与选择难度

1. 安装 PEAK 2.5.a 和 BepInEx 5，退出游戏。
2. 下载 [v1.5.17 安装包](https://github.com/Memnant/13-Downright-Dastardly-Ascents-Continued/releases/tag/v1.5.17) 并解压到游戏插件目录以外。
3. 使用下列脚本，`GamePath` 替换成自己的 PEAK 游戏目录。第一条只预览，第二条先备份再安装。

```powershell
.\tools\install.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\PEAK'
.\tools\install.ps1 -GamePath 'D:\SteamLibrary\steamapps\common\PEAK' -Apply
```

4. 在机场打开登机牌，启用续作模式并选择 9–20。无需逐个勾选低阶效果，它们会自动累加。

插件 GUID 保持为 `13dastardlyascents`，因此原模组与 Continued **只能加载一份**。安装器识别同 GUID 的旧 DLL，即使旧文件改过名字也会备份处理。手动安装时，把旧 DLL 移到 `BepInEx/plugins` 之外，再将新版放入 `BepInEx/plugins/PeakAscentsContinued/13dda.dll`；不要在 plugins 内放备份。

多人扩展挑战要求全员 **1.5.17**。房主同步等级和开关，版本或规则未确认时阻止开局。使用整合包/模组管理器时，须安装到实际启用的配置档案目录。

1.5.17 适用于 **2.5.a**；仍使用 2.4.c 的玩家请保留 **1.5.16**。本次只适配版本，逐阶难度和已调整数值不变。游戏升级涉及真实接口变化，因此没有直接取消版本保护。

## 配置与存档

- 配置文件：`BepInEx/config/13dastardlyascents.cfg`。
- `[Ascents]` 中 `Ascent 9` 至 `Ascent 20` 是**独立强制开启单阶**的开关，默认关闭；正常续作模式会自动累加。仅强制 20 不等于选择完整 20 阶。
- 保留 `Nerfed Revives`、`Curse Punishment for Ascent 10` 等仍适用开关；忽略旧 `Ascent 8` 和旧复活限制开关。
- 原生营火存档旁的模组规则保存在 `BepInEx/config/13dda-continued/runs/`，按 RunId 与检查点关联，包含本局等级、配置和岩浆相位。
- 可在 2.5.a 读取合法的 **2.4.c / Continued 1.5.0–1.5.16** 记录（保留 RunId 与原生检查点哈希核对），下一次实际保存才更新版本；没有模组记录的官方存档按官方模式处理。原作者旧模组的进行中高阶存档不自动迁移。
- 第三方自由存档格式尚不保证兼容。不要只恢复原生存档或只恢复侧存档，造成不匹配。

### 回退

安装器会打印本次真实备份目录。退出游戏，先预览再执行：

```powershell
.\tools\restore.ps1 -BackupDirectory '.\backups\install-实际时间及编号'
.\tools\restore.ps1 -BackupDirectory '.\backups\install-实际时间及编号' -Apply
```

默认回退 DLL 和配置、保留当前进度。退回 1.5.16 并不能让它在 2.5.a 运行，该版仍要求游戏 2.4.c。旧版未必能读取新版生成的侧存档；需要将进度也回到安装前时，给第二条命令加 `-RestoreSaves`，恢复成对备份的原生/侧存档，并另存回退前的当前存档。
