原作者多个包内的插件版本仍写 `1.3.1`，而 manifest 的发布版本不同。比较代码时以包版本和哈希区分，不能把内部版本相同当作 DLL 内容相同。

本项目的原模组设计、数值和差异说明来自上述本地样本的代码核查。作者 README 的简述与实际旧代码存在措辞差异，例如旧 8 阶写“立即起雾”，代码中的超时条件实际为超过 20 秒，原版玩家前进条件也可能更早启动；本项目按代码与实际适配入口说明。

原 README 把 18 阶概括为炎热恢复变慢 3 倍；已核对的旧代码实际写入 `0.00333333/秒`。本项目保留该原参数；新增雾沼/城塞困倦恢复的 1/6，是相对 16 阶白天困倦 `0.02/秒` 而言，不能将两个基准混为一谈。

## 不同于原作者版本的主要方向

1. 兼容新版官方天阶 7/8、物品、状态与原生存档；续作 9–20 独立管理，不写入官方解锁。
2. 原 8 阶强化追赶雾移至 18，增加雾沼追赶睡眠与地区恢复规则。
3. 新增城塞倦霾、天底石化雾速度调整，以及新版滑翔翼适配。
4. 修复领队会合清除、岩浆各端独立计时、天气范围/原生雪暴补建和额外龙卷风空气墙问题。
5. 新增房主免宝石选项、20 阶开局保护与天气缓冲，并按玩家反馈调整毒伤、天气停歇、雾沼增长与恢复。
6. 限定恢复龙卷风卷起后的装死切道具技巧，不取消普通坠落限制。

所有当前数值和作用范围以 [README](../README.md) 与 [EFFECTS.md](EFFECTS.md) 为准。与原作者相比哪些是相同规则、哪些属于新功能、哪些只做了接口修复，已逐阶列明。
