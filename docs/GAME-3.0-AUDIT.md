# PEAK 3.0 适配核查

核查日期：2026-10-23。插件：1.5.22；PC Steam Build 26134529；Unity 6000.3.15f1。

## 官方更新与实际文件

[官方 CROSSPLAY HAS ARRIVED TO PEAK 公告](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1847286114033058) 宣布主机跨平台联机、208 张地图池，以及将地图放入 assetbundle。公告提醒模组通常不能与主机玩家一起使用；本续作仍要求所有 PC 玩家安装同版。

本机 `version.txt` 首行实际为 `3.0.0--logFile`；游戏日志的网络版本为 `3.0`。本版精确识别这一文件标签，不改写官方文件。主程序集 SHA-256 为 `E9A8585ABFA566AFA7A3EF3E3699BC27369039EEEFCDB3CAA38D624D56F59E5C`，MVID 为 `b5521262-0ce1-4a6c-a2bb-f18e027e413e`。

## 接口与行为对比

对照本地保留的 2.6.a 测试副本和当前 3.0 程序集。旧副本只在历史兼容性测试中改过 MVID，方法体可用于比较；并未把该副本当作未经修改的官方文件哈希。

本模组 98 个不同补丁目标中，发现两个目标的方法体变化：

| 目标 | 3.0 变化 | 本次处理 |
|---|---|---|
| `AOE.Explode` | 通过 `CharacterRagdoll.TryGetCharacterFromCollider` 注册表识别角色 | 模组强化爆炸沿用新版查找，保留原参数；避免旧父级组件查找遗漏新版角色碰撞体 |
| `CharacterMovement.ApplyParasolDrag` | 原版公共减速流程调整 | 现有补丁仍仅限制阳伞，不接管滑翔翼飞行；保留新版物理 |

已检查状态、坠落、原生天气目标与直接引用成员。天阶数值和 1.5.18/1.5.19 的队员规则、天气阶段同步保持；没有新增房主重复施加伤害的逻辑。接口与目标方法核查不代表所有间接依赖和实际联机都已验证。

## 地图与原版雪暴资源

3.0 的 `MapBundleService` 按地图名从 `StreamingAssets/maps/` 加载资源包。原版雪暴的位置已变化，提取器改从已核查的 `levels0-31.assetbundle` / `BuildPlayer-Level_22` 及其共享资源读取。

使用可寻址流和 8 MiB 解压块缓存，按需读取元数据与资源。对重新打包的 9 个视觉对象进行字段比较，和上一版内容一致；纹理载荷也一致。14 项块边界、随机范围及流读取检查通过。资源定位在构建时完成，游戏运行时不解包大型地图包。

## 原生存档

`Quicksave.SaveData.k_CurrentVersion` 仍为 **4**，RunId、检查点和时间字段保留；新加载流程会按存档地图名加载对应资源包。没有证据表明所有 2.6 格式 4 存档都会被原版拒绝。

由于地图池及跨平台用户身份相关流程更新，本版不自动迁移旧续作进行中记录，保留旧文件和配置。新建的 1.5.22 / 3.0 记录仍可同系列向前读取，核对原生格式、RunId 和检查点哈希。测试不调用会删除不兼容旧文件的原生 `TryLoadSave`。

## 3.0.1 补充核查（1.5.23，2026-10-27）

本机自动更新到 **PEAK 3.0.1 / Steam Build 26155610**，`version.txt` 首行为 `3.0.1--logFile`；主程序集 SHA-256 `E526A5234EA2289EA55297FBD6FB7626C75E86E6A0A26A6B87D82ED8F44CD168`，MVID `136be7ad-59b8-46b6-803a-88c02a9d5c13`。1.5.22 只识别 `3.0.0--logFile`，因此在 3.0.1 上会自动停用。

以历史兼容性测试保留的 3.0.0 副本（MVID `b5521262…`，仅改动 `k_CurrentVersion` 常量）逐方法对比：只有 `MainMenuJoinRoomPage` 的加入房间流程变化（新增 14、删除 21、修改 3 个方法）。本模组 104 个补丁目标的签名和方法体均未变化，检查的存档字段未变化，原生存档格式仍为 4。1.5.23 据此把 3.0.1 设为已核查基线，并把加载门槛放宽到 3.x 数字版本。
