# 1.5.21：放宽版本限制实验版

本版允许 PEAK **2.6 系列字母补丁**尝试加载，例如 `2.6.a`、`2.6.b`。当前检查基线仍是 **2.6.a / Build 25667990**；不放行 `2.7`、`3.x`、`2.60` 或不符合字母后缀格式的版本。

## 更新后可能出现的问题

**允许加载不等于保证兼容。** 官方可能保留相同接口，却改变内部规则、资源、网络事件或存档内容。未来更新后可能发生天气不同步、推力或伤害异常、睡眠增长/恢复异常、道具失效、营火续玩失败或进度异常。这些是尚未验证的风险，并非声称已经在未来版本复现。

- 升级前备份原生 `quicksave.peak` 与 `BepInEx/config/13dda-continued/runs/`，两者应成对保留；同时保留配置和旧 DLL。
- 房主和队员使用相同的游戏与模组版本。此版模组版本检查仍要求全员 1.5.21，未放宽联机版本一致性要求。
- 出现异常时停止用该组合推进重要存档，记录游戏完整版本、模组版本、天阶、地图、新局或续玩、房主或队员及复现步骤，并附相关错误日志。分享前删去私人标识。
- 回退 DLL 不能回退游戏或把新存档转换成旧格式。1.5.20 仍仅面向 2.6.a；需要恢复旧进度时使用匹配版本及成对备份，先保留当前文件。

## 启动检查具体做什么

在安装 Harmony 补丁前，只读检查游戏与插件程序集元数据：补丁目标是否存在且无歧义、注入参数与字段是否匹配、直接引用的游戏/Unity/网络等成员能否解析、原生存档格式是否仍为 4，以及 RunId、检查点区域和时间字段是否保留。

发现结构不匹配就停用插件并输出原因。接口相同但游戏版本或程序集构建标识不同于已检查基线时，会输出实验兼容警告，然后尝试加载。检查只在启动时执行一次，不增加每帧扫描；不会改写游戏程序集或转换原生存档。

它无法证明方法内部行为、资源布局、第三方模组或实际多人流程仍然兼容。游戏自身及其他模组的存档读写也不受此检查保护。

## 存档边界

- 侧存档仍使用 schema 2，新增记录实际游戏版本和 `nativeSaveVersion`，不再把未来补丁误记为 2.6.a。
- 已知 2.6.a / 1.5.20 的合法记录可以读取；其缺少的新字段按已核查的原生格式 4 处理，实际原生文件仍须通过格式和哈希核对。
- 1.5.21 的记录仅允许同系列、同格式的相同或向前字母补丁读取；不支持降级，不迁移 2.4/2.5 的旧进行中存档。
- 读取不会重写记录；下一次成功保存才写入当前版本。缺少模组记录的有效官方存档继续走官方模式。
- 原生存档格式改为 5 等其他值时，即使仍叫 2.6 系列，也必须重新适配。

## 本版范围

天阶 9–20 数值、天气同步、天气间隔、睡眠与摔伤、追赶雾、免宝石选项均沿用 1.5.20。本轮只调整兼容性门禁及相关侧存档记录，增加测试和风险说明。

未来补丁的检查是合成测试：在当前程序集副本上模拟版本、接口或格式变化，未获得真实未来版本来游玩。实际测试范围见 [TESTING.md](TESTING.md)。构建时的视觉资源提取器继续限定已核查的 2.6.a，不盲目提取未知资源。
