# 1.5.23：PEAK 3.0.1 适配候选

已核查基线是 PC 版 **PEAK 3.0.1 / Steam Build 26155610**。本版把加载门槛放宽到 **整个 3.x 系列的数字版本**（例如 `3.0.2`、`3.1.0`、`3.12.4`），只要启动时的接口检查和原生存档格式检查通过就会尝试加载。不放行 `2.x`、`4.x`、字母版本、前导零或任意附加后缀。

Steam 构建的 `version.txt` 首行形如 `3.0.1--logFile`。插件只剥离"合法 3.x 数字版本 + 恰好一个 `--logFile`"这一种后缀，不修改游戏版本文件；大小写不同、带空格或重复的后缀都不识别。不是 3.0.1 已核查程序集的版本，会输出未验证警告。

## 官方更新后的边界

**允许加载不等于保证兼容。** 小版本（例如 3.1）可能改变内部行为、资源、网络或存档，即使接口没变也可能出现天气不同步、伤害/睡眠异常、道具失效或营火续玩失败。升级前成对备份 `quicksave.peak` 与 `BepInEx/config/13dda-continued/runs/`，并保留配置和旧 DLL。

- 房主及队员必须使用相同游戏版本和 **1.5.23**；联机版本一致性检查没有放宽。
- 本模组面向可安装 BepInEx 的 PC 玩家，不支持混入未安装模组的主机版玩家。官方 3.0 的主机跨平台功能不等于本模组支持跨平台。
- 出现异常时记录完整游戏/模组版本、天阶、地图、新局或续玩、房主或队员及复现步骤。分享日志前删去私人标识。
- 回退 DLL 不会回退游戏或转换存档。1.5.21 面向 2.6，不能用于修复 3.x。

## 启动检查

Harmony 安装补丁之前，只读检查目标、参数、注入字段、直接引用成员及原生存档格式 4、RunId、检查点区域和时间字段。结构不匹配则停用并记录原因。检查只在启动时执行一次，不新增每帧扫描，也不改写游戏程序集。

模组按名称修改的游戏参数若在新版本中被改名，只停用该单项效果并在日志中记录一次，不再每帧报错。

检查无法证明内部行为、资源布局、第三方模组或真实多人流程正确；游戏自身及其他模组的存档操作也不受此检查保护。

## 存档

- schema 2 继续记录实际游戏版本、插件版本、原生格式、RunId、检查点哈希和本局规则。
- **1.5.22 及以后写入的 3.x 侧存档，可由同版本或更新的模组读取**（例如 1.5.22 在 3.0.0 存的营火档，可在 1.5.23 + 3.0.1 继续）。旧模组不读取新模组的记录。
- 游戏版本只允许向前：按数字比较，例如 3.0.9 → 3.1.0、3.9.0 → 3.10.0 允许，反向降级或跨到 4.x 拒绝。
- **不自动把 2.6 / 1.5.21 及更早的续作进行中存档迁到 3.x**，识别到会取消续作加载并保留文件。
- 读取不重写记录，下次保存才更新版本；原生文件或侧存档不匹配时保留文件。没有模组记录的有效官方存档按官方模式处理。
- 原生格式变为 5 或其他值时，即使仍是 3.x，也需要重新适配。第三方自由存档格式未验证。

## 本次改动范围

天阶 9+ 爆炸改为放大原版参数并让原版逻辑执行；天阶 14+ 天气恢复原版大风攀爬耗体力；按名称修改的参数改为编译期检查并在缺失时安全跳过；适配 3.0.1 并放宽到 3.x。天阶 9–20 其余数值、睡眠与摔伤、追赶雾、天气同步和间隔、免宝石选项保持。

真实 3.0.1 程序集已用于编译和隔离 Unity 加载；未来版本仅用合成测试模拟，不能据此宣布兼容。完整证据见 [3.0 核查](GAME-3.0-AUDIT.md) 与 [测试说明](TESTING.md)。
