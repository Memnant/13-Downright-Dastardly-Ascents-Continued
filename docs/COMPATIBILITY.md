# 1.5.22：PEAK 3.0 适配候选

已核查基线是 PC 版 **PEAK 3.0.0 / Steam Build 26134529**，允许 **3.0.x 数字补丁**在接口检查通过后尝试加载，例如 `3.0.1`、`3.0.10`。不放行 `2.6`、`3.1`、`4.x`、字母补丁、前导零或任意附加后缀。

该 Steam 构建的 `version.txt` 首行为 `3.0.0--logFile`。插件仅将这个已核查的完整字符串识别为 `3.0.0`，不修改游戏版本文件。后续补丁或不同程序集构建标识会输出未验证警告。

## 官方更新后的边界

**允许加载不等于保证兼容。** 接口相同也可能伴随内部行为、资源、网络或存档变化。未来补丁仍可能出现天气不同步、伤害/睡眠异常、道具失效或营火续玩失败。升级前成对备份 `quicksave.peak` 与 `BepInEx/config/13dda-continued/runs/`，并保留配置和旧 DLL。

- 房主及队员必须使用相同游戏版本和 **1.5.22**；联机版本一致性检查没有放宽。
- 本模组面向可安装 BepInEx 的 PC 玩家，不支持混入未安装模组的主机版玩家。官方 3.0 的主机跨平台功能不等于本模组支持跨平台。
- 出现异常时记录完整游戏/模组版本、天阶、地图、新局或续玩、房主或队员及复现步骤。分享日志前删去私人标识。
- 回退 DLL 不会回退游戏或转换存档。1.5.21 面向 2.6，不能用于修复 3.0。

## 启动检查

Harmony 安装补丁之前，只读检查目标、参数、注入字段、直接引用成员及原生存档格式 4、RunId、检查点区域和时间字段。结构不匹配则停用并记录原因。检查只在启动时执行一次，不新增每帧扫描，也不改写游戏程序集。

检查无法证明内部行为、资源布局、第三方模组或真实多人流程正确；游戏自身及其他模组的存档操作也不受此检查保护。

## 存档

- schema 2 继续记录实际游戏版本、插件版本、原生格式、RunId、检查点哈希和本局规则。
- **不自动把 2.6 / 1.5.21 及更早的续作进行中存档迁到 3.0。** 3.0 仍使用原生格式 4，但地图池及加载流程已变，未完成跨大版本续玩验证，因此模组识别到旧侧存档会取消加载并保留文件。此限制不表示原版拒绝所有 2.6 格式 4 存档。
- 1.5.22 的合法记录允许同一 3.0 系列、同原生格式的相同或向前数字补丁读取；按数字比较，例如允许 3.0.2 → 3.0.10，不允许反向降级。
- 读取不重写记录，下次保存才更新版本；原生文件或侧存档不匹配时保留文件。没有模组记录的有效官方存档按官方模式处理。
- 原生格式变为 5 或其他值时，即使仍叫 3.0.x，也需要重新适配。第三方自由存档格式未验证。

## 本次改动范围

适配 3.0 爆炸碰撞体到角色的注册表查找；更新原版雪暴构建提取器，支持新的地图资源包。天阶 9–20 数值、睡眠与摔伤、追赶雾、天气同步和间隔、免宝石选项保持。

真实 3.0 程序集已用于编译和隔离 Unity 加载；未来补丁仅用合成测试模拟，不能据此宣布兼容。完整证据见 [3.0 核查](GAME-3.0-AUDIT.md) 与 [测试说明](TESTING.md)。
