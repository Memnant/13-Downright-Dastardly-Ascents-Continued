# PEAK 2.6.a 适配核查

检查日期：2026-10-03。目标 **PEAK 2.6.a / Steam Build 25667990**，发布候选 **Continued 1.5.20**。

## 失效原因

本机版本文件是 `2.6.a`，已安装的 DLL 为 1.5.19，SHA-256 为 `EA1AE026AF22779C4870D28C0853744059C72535DAA6507A81AE416D8FA6B33A`。其 `Plugin.Awake` 仍要求 `2.5.a`，检测到新版本会退出加载并撤销自身补丁。这条明确的版本门禁足以解释升级后的整体停用。

当时 BepInEx 磁盘日志为空，不能把没有错误行当作成功加载。Unity 日志确认游戏的网络版本已为 2.6，并记录了原版拒绝不兼容营火档的消息。私人日志未公开。

## 新版本代码与保留范围

对比保存的 2.5.a 编译引用副本和本机 2.6.a 原程序集，并对本模组涉及的补丁和引用成员重新解析：

- **103 个补丁声明、98 个不同目标**在 2.6.a 中均可解析和隔离注册。状态、跌落、天气时钟、攀爬和物品相关补丁没有发现本次必须重写的接口变化。
- 原生 `WindChillZone` 的受检天气逻辑未改变。1.5.19 的房间天气阶段、风向、渐入与晚加入恢复原样保留，睡眠惩罚及各阶参数也未改动。
- 2.6 调整了重连用户标识处理、营火附近物品记录和复活/传送周边逻辑；本版继续让这些流程由游戏执行，不恢复旧实现。
- 从 2.6 的 `data.unity3d` 重新定位原生雪暴粒子，更新提取器的版本、程序集哈希和资源对象 ID。比较输出中的 9 个非索引视觉对象，粒子、材质、纹理等字段与 1.5.19 相同。运行时不解包游戏文件。

此次运行时源码的有效改动仅为插件版本与受支持游戏版本；另有存档边界注释、构建提取器、安装器、测试和文档更新。保留精确版本检查，不宣称未经核查的后续游戏更新自动兼容。

## 原生存档边界

2.6.a 的 `Quicksave.SaveData.k_CurrentVersion` 从 **3** 改为 **4**，构造新档时写入 4，原版加载判定仅接受 4。同时，恢复玩家数据从用户标识的哈希字符串比较改为直接比较字符串标识。

因此不能把 2.5 的旧营火档改一下版本号就宣称兼容。本版不接管原版的旧档转换，也不让 2.4/2.5 的旧侧存档通过 2.6 的检查。旧配置和侧存档文件在安装时备份并保留；新局保存后，以 **2.6.a / 1.5.20** 写入 schema 2 侧存档，继续校验 RunId 和原生检查点哈希。没有模组记录的有效 2.6 官方存档按官方规则处理。

本机安装前原生 `quicksave.peak` 已不存在；本次检查及安装没有删除或恢复它。若旧营火档因官方升级不再可用，需要开始新局。回退 DLL 不会回退游戏版本。

## 验证结果

编译、静态接口解析、39,794 项模型断言及隔离 Unity 回归通过。额外调用原生存档版本判定，确认格式 4 接受，0/2/3/5 拒绝，RunId/检查点区域/时间字段仍可读取；这个测试没有调用会删除旧档的 `TryLoadSave`。

隔离加载还重跑了原有规则接收、摔伤睡眠、天气阶段、雾伤害、地区状态、道具及参数恢复检查。安装器回滚模拟通过，本机安装后确认游戏程序集和 49 份配置/侧存档文件保持原哈希。

**真实双客户端、实际画面和受力、营火保存/加载往返、完整整合包仍未验证。** 数值断言与模拟回调不代表已经完成多人游戏验收。完整范围见 [TESTING.md](TESTING.md)。
