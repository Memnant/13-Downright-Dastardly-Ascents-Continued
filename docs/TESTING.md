# 1.5.19 天气同步候选：测试与边界

检查日期：2026-09-29。目标 PEAK **2.5.a / Build 25585932**，BepInEx **5.4.23.3**，Unity **6000.3.15f1**。

DLL SHA-256：`EA1AE026AF22779C4870D28C0853744059C72535DAA6507A81AE416D8FA6B33A`。

## 本次依据

玩家最新反馈睡眠惩罚已恢复，但队员显示“续作天阶 20”时，森蕈风、暴风雪、雨仍可能不同步。对比确认 1.5.16/17 的规则、摔伤和天气源码相同，不能把 1.5.18 的时序修复当作 2.5 更新后所有异常的唯一根因。

在已发布的 1.5.17、1.5.18 DLL 中分别重现两种合成时序：原生天气开始 RPC 在等待缓冲状态时被抑制，随后无法恢复当前阶段；新房主尚未离开菜单时，把运行中的房间误发布为未开局。1.5.19 分别增加原生天气房间阶段和加载途中的接管保护。详见 [完整排查](MULTIPLAYER-2.5-AUDIT.md)。

## 尚未验证

- **真实双客户端**：新开局、营火续玩、晚加入、重连和房主离开后的三种天气开始/停止、方向、画面、受力与状态增长。
- 实际地图中的营火存档往返，以及整个整合包的兼容性。
- 真正网络延迟、丢包和不同帧率下的体验及整机性能。
- 此次没有取得故障房间的双端日志，因此尚不能认定已复现其完整现场。

建议复测时双方安装同一 1.5.19 DLL，在同一位置比较天气，避开不同安全区/光照保护的影响。日志的 `Continued weather phase` 每阶段记录一次；双方类型、clock、duration、direction 应匹配。它不记录玩家、房间或 Steam 标识。天空/粒子插值和实际风力仍须游戏内观察。
