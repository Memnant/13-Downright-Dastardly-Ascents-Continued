# 1.5.17 测试与已知边界

检查日期：2026-09-29。目标 PEAK **2.5.a / Build 25585932**，BepInEx **5.4.23.3**，Unity **6000.3.15f1**。

DLL SHA-256：`D96C3C3551F578A25D426F07E7E60C9D4C2089560673894AEE61EF1B0468863E`。

## 本次修复的依据

1. 1.5.16 启动时只接受 `2.4.c`，因此遇到 `2.5.a` 会主动移除补丁并停用。
2. 2.5 的 `CharacterAfflictions.AddStatus` 从六参数变为七参数，`SetAll` 从一参数变为两参数；新参数为 `ignoreSkeleton`。旧 DLL 即使绕过版本检查，仍引用不存在的旧方法签名。
3. 追赶雾的转接方法已接收并转交新参数。其余直接状态调用按当前游戏程序集重新编译；保留原生状态锁、无敌判断及重连时的骷髅处理。
4. 2.5 将资源合并到 `data.unity3d`，旧提取脚本不能直接找到散装地图资源。新版工具只读取相关块，提取范围仍为九个原生粒子/材质/着色器/纹理对象，不包含地图。

## 存档迁移边界

支持的迁移只放宽已知的旧游戏/旧模组版本组合；schema 2 的原生存档 SHA-256、RunId、检查点参数和岩浆相位校验保留。读取时不改写旧文件，下一次实际营火保存才写入新版本。没有侧存档的官方存档按官方规则处理。

模型测试确认记录可读，不代表已经在真实地图执行完一次营火续玩。恢复为 1.5.16 还要求游戏本身是 2.4.c；仅回滚插件不能解决新游戏与旧接口的不兼容。
